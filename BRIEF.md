# kp — коммерческие предложения ссылкой

Публичные страницы КП SolutionCRM для клиентов. Одна КП = одна папка `p/<случайный-код>/index.html`.
Страницы закрыты от поисковиков (noindex), но открываются у всех, у кого есть ссылка. Репозиторий публичный.

## Правила
- Только текст КП. Без телефонов, почт, реквизитов и выгрузок клиентов.
- Код папки — случайный, чтобы ссылку нельзя было угадать.

## Публикация
Выкладка по умолчанию: GitHub Pages (ветка main, корень).
