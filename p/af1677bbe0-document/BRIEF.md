# Защищённый документ SolutionCRM

Задача: просмотр готового PDF по ссылке с одним полем пароля, без логина.

Выкладка по умолчанию: GitHub Pages, существующий репозиторий kp, main, корень.

Адрес: https://spartakkinzyabulatov-lgtm.github.io/kp/p/af1677bbe0-document/

Публикуются только форма просмотра и зашифрованный payload.json. PDF зашифрован AES-256-GCM, ключ выводится из пароля через PBKDF2-SHA256, 600000 итераций, случайные salt и IV. Пароль и исходный PDF в репозиторий не попадают. Расшифровка выполняется в памяти браузера. После закрытия Blob URL отзывается, перезагрузка требует пароль заново. Короткий пароль выбран пользователем как требование к формату доступа; статическая публикация допускает офлайн-перебор.

Есть просмотр, открытие PDF в отдельной вкладке, скачивание и закрытие. На телефоне доступна отдельная кнопка открытия PDF. PWA и sw.js не используются.
