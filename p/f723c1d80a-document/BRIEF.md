# Защищённый документ SolutionCRM

Задача: заметка от лица Спартака по данным CRM, с чётким текстом и графиками, просмотр по короткому паролю без логина.

Выкладка по умолчанию: GitHub Pages, существующий репозиторий kp, main, корень.
Адрес: https://spartakkinzyabulatov-lgtm.github.io/kp/p/f723c1d80a-document/

Публикуются форма входа и зашифрованный payload.json. Содержимое — адаптивный HTML с настоящим текстом и SVG/CSS-графиками, без растровых страниц. Шифрование AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600000 итераций, случайные salt и IV. Пароль и незашифрованный материал в репозитории не хранятся. Расшифровка в памяти вкладки, закрытие очищает расшифрованный документ из DOM, перезагрузка снова требует пароль. Короткий пароль допускает офлайн-перебор.

Просмотр обычного текста и векторных графиков в изолированных стилях Shadow DOM, печать / сохранение PDF средствами браузера. Документ содержит собственные печатные стили. PWA и sw.js нет.
