# Материалы по строительству

Задача: передать коллеге существующие документы SolutionCRM по одной ссылке с паролем.

## Содержимое
- Риски и экономика халяль-рассрочки: исходный интерактивный HTML с финмоделью.
- Обезличенная аналитика базы застройщика: исходный интерактивный HTML.
- Исследование от 18.11.2026: итог и четыре заметки, преобразованные в HTML. Личные данные и банковские сведения исключены из опубликованной копии.

## Публикация
Выкладка по умолчанию: GitHub Pages, существующий репозиторий kp, main, корень.
Адрес: https://spartakkinzyabulatov-lgtm.github.io/kp/p/6d41fa98-stroyka/

Документы содержатся только в зашифрованном payload.json. Шифрование AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600000 итераций, случайные salt и IV. Пароль и ключ не записаны в репозиторий. Короткий пароль допускает перебор; это ограничение статической публикации, пользователь уведомлён. Расшифрованные документы существуют только в памяти вкладки. Кнопка закрытия отзывает Blob URL. Перезагрузка снова требует пароль.

PWA и sw.js не используются. index.html — форма входа и просмотр, payload.json — зашифрованные документы. Исходные файлы не менялись.
